## 关于我

我是 JiFu Lian，从企业级全栈开发出发，持续探索 AI Agent 与复杂系统的工程实践。

我关注从界面、接口到运行反馈的完整过程：功能如何落地，故障如何定位，结果如何验证。在 AI Agent 方向，我尤其关心工具调用、上下文管理、任务状态，以及执行失败后的恢复机制。

这里记录我的项目、源码阅读和技术写作，包括实现方法，也包括设计取舍与尚待解决的问题。
